# Spotify Music Analytics Dashboard
Spotify Music Analytics Dashboard | Artist, Song & Popularity Insights

# Short Description
- An interactive Spotify analytics dashboard that provides insights into song popularity, artist performance, album types, release trends, and listening patterns.   The dashboard helps users explore music trends and identify top-performing artists and songs.

# Purpose
The purpose of this dashboard is to:
-Analyze Spotify song and artist performance.
-Track popularity trends across months and years.
-Compare album types (Albums vs Singles).
-Understand explicit vs non-explicit song distribution.
-Identify top artists and most popular songs.
-Support music industry decision-making using data-driven insights.

# Key Insights from Dashboard
**Popularity Metrics**
-Average Song Popularity: 89.62
-Total Artists: 342
-Total Songs: 789
-Average Duration: 3.28 Minutes

**Album Performance**
-Albums dominate the catalog compared to singles.
-Album tracks show slightly higher popularity than singles.

**Artist Performance**
-Taylor Swift leads in song count and popularity.
-Several artists contribute significantly to the music catalog.

**Monthly Trends**
-Highest average popularity observed in January (92.5).
-Lowest popularity observed in October (86.9).
-Popularity rebounds toward year-end.

**Song Releases**
-October shows the highest number of distinct songs released.
-July and November also have strong release volumes.
